# SUBSTRATE PRO | Associative Documentation v2.2

## Connected workflow
1. Draw wall, slab, beam or column in Plan. Place hosted Door/Window on wall.
2. Select assembly, edit geometry, material, level, classification, optional Assembly Tag; Apply Properties.
3. Use Auto Author / Publish to inspect model-derived tags, opening associations and net volumes.
4. Use Plot / Sheet Setup for paper size, scale, title block and one/four coordinated views.
5. Toggle Auto tags + dimensions on plots and regenerate after revisions. Export SVG/PDF from the sheet composer; export schedules as CSV.

## Limitations
- Camera view is a projected model viewer, not true OCCT solid B-rep.
- Automatic dimensions currently cover wall/beam lengths, not full dimension chains or collision-optimized text.
- Quantities are conceptual rectangular material approximations; no pricing, certified BIM exchanges, ISO validation, or automatic structural connection shop drawings.
- Preserve project JSON using Save. Exports are snapshots; rerun the sheet composer after editing.
